HELPING WITH THE EMPIREMUD SOUNDPACK

This repository is the whole soundpack: MUSHclient plus the EmpireMUD sounds
and triggers. New players can download it with GitHub's "Download ZIP" and
run MUSHclient.exe.

Whatever reaches the main branch here goes to players by itself. Everyone's
soundpack checks GitHub when it opens and downloads the new and changed
files in worlds\empire.

HOW TO HELP
1. Fork this repository on GitHub, or ask the owner to add you as a
   collaborator. MUSHclient's own settings files (mushclient_prefs.sqlite,
   MUSHclient.ini, worlds\world.MCL and worlds\plugins\state) aren't kept in
   git, because they change every time you play. If your copy came straight
   from git and MUSHclient has no world file, speech or sound, copy
   everything in the defaults folder into the soundpack folder.
2. Make your change in worlds\empire. Sounds go in the folder that fits
   them, as .ogg files. Lua scripts are in worlds\empire and
   worlds\empire\updater.
   The soundpack's triggers, aliases, timers and macros are in
   worlds\empire\soundpack.xml. Change or add them in MUSHclient the usual
   way (Game, Configure), then type spexport. That saves them all into
   soundpack.xml, which is the file you commit. If you don't type
   spexport, your change stays only in your own MUSHclient and is lost
   when you close it. spexport also saves any triggers or aliases you made
   for yourself, and says how many new ones it found, so delete any you
   don't want everyone to get first.
3. Test it in your own copy of the soundpack.
4. Send a pull request, or push to main if you're a collaborator.

RULES
Only add sounds you're allowed to share.
Keep each file under 50 MB.
Say what you changed and what triggers it in the game. Players hear the
first line of your commit message when their soundpack updates, so write
it for them, like "New sounds for swords".
