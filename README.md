# EmpireMUD soundpack

Sounds for EmpireMUD, built into MUSHclient, ready to play.

## Download

[Download empiremud-soundpack.zip](https://github.com/jlvp1998/empiremud-soundpack/releases/download/soundpack/empiremud-soundpack.zip)

Unzip it, open the empiremud-soundpack folder, and run MUSHclient.exe.

The soundpack updates itself. A few seconds after you open it, it checks for new sounds and downloads them. To check again without restarting, type spupdate.

Updates need Windows 10 or 11. If Windows Defender's Controlled Folder Access is on, don't put the soundpack in Documents or Desktop, because Defender stops it from updating there. Put it somewhere like C:\empiremud-soundpack instead.
